# 数据说明：哪些是合成的，哪些是公开的

> 一句话：**仓库里没有一条真实病历。** 病例全部是脚本生成的，药品 / 问答 / 疾病词表来自
> 可以自由再分发的公开数据源。

---

## 一、合成数据（本项目生成）

| 文件 | 条数 | 怎么来的 |
|---|---|---|
| `data/样例数据/病例样例.jsonl` | 204 | `tools/生成样例数据.py` |
| `data/样例数据/症状样例.jsonl` | 53 | 同上（各科室症状去重导出） |

### 怎么证明它是合成的

1. 生成脚本就在仓库里：`tools/生成样例数据.py`（100 多行，纯 `random`，没有任何外部数据）
2. **随机种子固定**：`random.seed(20260101)`，任何人重跑都得到**逐字节相同**的文件：

```bash
python tools/生成样例数据.py
git diff data/样例数据/        # 应该没有变化
```

3. 字段全由程序拼装：

```python
sx     = random.sample(info["symptoms"], k=random.randint(2, 3))   # 症状
disease = random.choice(info["diseases"])                          # 诊断
drugs  = random.sample(info["drugs"], k=random.randint(1, 3))      # 用药
text   = "症状：%s %s。患者%s，%d岁。既往史：%s。诊断：%s。用药：%s。"
```

4. 内容本身也不装真实：`case_id` 是 `sample_001…`，年龄是随机整数，
   症状/诊断/用药是**随机组合**（所以会出现"小儿肺炎 + 65 岁"这种不合理的搭配）。
   **它只用于演示界面和检索链路，不是医学数据。**

### 为什么不做成"像真的"

故意保留随机组合：这样任何人一眼就能看出是样例，不会误当成真实病历使用。

## 二、公开数据（可自由再分发）

| 文件 | 条数 | 来源 | 许可 |
|---|---|---|---|
| `data/开放数据/药品_openfda.jsonl` | 1000 | [openFDA](https://open.fda.gov) 药品说明书 | **CC0-1.0**（公共领域） |
| `data/开放数据/问答_medquad.jsonl` | 2000 | [MedQuAD](https://github.com/abachaa/MedQuAD)（NIH 患者教育问答） | **CC BY 4.0** |
| `data/开放数据/疾病词表_doid.jsonl`（`--doid` 才下） | 约 1.5 万 | [Disease Ontology](https://github.com/DiseaseOntology/HumanDiseaseOntology) | **CC BY 4.0** |

- openFDA：FDA 官方声明公共领域 / CC0，"可以复制、修改、分发，商用也不用问"
- MedQuAD：CC BY 4.0，**再分发要保留署名**（每行 JSONL 里有 `license` 字段）
- Disease Ontology：CC BY 4.0，同样需要署名

重新抓（数据会更新）：

```bash
python tools/下载开放数据.py --openfda 1000 --medquad 2000
python tools/导入开放数据.py --rebuild
```

## 三、刻意**不包含**的数据

| 数据 | 为什么不在仓库里 |
|---|---|
| MIMIC-IV / eICU-CRD / MIMIC-Note | PhysioNet 使用协议**禁止再分发**，要自己申请 + 培训 + DUA |
| 中国医药信息查询平台（dayi） | 内容有版权，只能本地研究（`tools/爬dayi.py`，遵守 robots） |
| Huatuo / CMB 等中文医学集 | 各自许可证不同，用前自己看清 |
| 任何真实病历 / 检查报告 | 隐私 |

由这些数据派生的**病例库、向量、全文索引**同样受协议约束，不要提交到公开仓库。
（`data/` 目录已被 `.gitignore` 排除，`.env`、token 也在里面。）

## 四、演示站用的是哪份数据

演示站（<https://medipipe-demo.menghuan.cloud>）用的是**扩大版的同一批公开数据**：

- 3,000 条合成病例（`tools/生成样例数据.py 3000`）
- 20,000 条 openFDA 药品
- 16,000 条 MedQuAD 问答
- 15,000 条 Disease Ontology 疾病词表

全部免费公开、可再分发；没有任何真实病历。
