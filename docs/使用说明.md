# 使用说明（从零到跑起来）

> 目标：10 分钟内看到两个界面在跑，并且知道每个按钮是干什么的。

---

## 0. 先自检

```bash
python tools/自检.py
```

它会逐项检查 Python 版本、依赖、数据库、向量、Ollama、模型、Key、端口，
不合格的会直接告诉你**下一步敲什么命令**。先跑到「结论：可以跑了」再往下。

---

## 1. 装环境

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
# source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt   # 版本已锁死
```

Windows 也可以双击 `setup.bat`。

---

## 2. 装本地模型

```bash
ollama pull bge-m3        # 向量（相似病例必需，1024 维）
ollama pull qwen2.5:3b    # 翻译（可选，一个词 0.2 秒）
ollama pull qwen3-vl:4b   # 读图 / 没 Key 时的本地总结（可选）
```

Ollama 没装也能启动：关键词检索、概览、药品说明照常，
相似病例 / 翻译 / 读图会提示不可用。

---

## 3. 导入数据

```bash
# 合成病例（204 条）+ 建向量
python tools/导入样例数据.py

# 公开数据（1000 药品 + 2000 问答）+ 全文索引
python tools/导入开放数据.py
```

想要更多数据（演示站就是这么喂的）：

```bash
python tools/下载开放数据.py --openfda 20000 --medquad 0 --medquad-zip --doid 99999
python tools/导入开放数据.py --rebuild
```

---

## 4. 启动两个界面

```bash
# 检索端（日常用这个）
python -m streamlit run framework_b/app_b.py --server.port=8502

# 生产端（要接新数据源时才用）
python -m streamlit run app.py --server.port=8501
```

Windows 双击 `2_启动框架B_检索.bat` / `1_启动框架A_生产.bat`。

---

## 5. 检索端怎么用（5 个页签）

| 页签 | 怎么用 |
|---|---|
| **概览** | 看库里有多少表、多少行、索引在不在。数字对不上就是没导数据 |
| **相似病例** | ① 选部位（可多选）② 写症状 ③ 填既往史 → 点「找相似病例」。结果分 5 个子页：类似疾病 / 治疗药物 / 常用药物 / 总结 / 查看病例。表格里**点任意一行**能看那个病或药的说明 |
| **关键词检索** | 直接搜（中英文都行）。有全文索引走 BM25；没有就自动退回 LIKE（慢但能出结果）。「结果语言」切换只影响显示，不会丢结果 |
| **病历总结** | 粘文本或传照片 → 六段（主诉/现病史/既往史/关键检查/诊断/处理）。默认走主模型（需要 Key，2~5 秒）；没 Key 可勾「用本地模型」（20~60 秒） |
| **自检** | 三盏灯（数据库 / 本地模型 / 主模型）+ 填 Key。Key 存在 `.env` 的 `MY_LLM_KEY`，和框架 A 共用 |

小技巧：
- 相似病例里点了「翻译成中文」，会同时翻疾病名、药名、**科室分布里的代表疾病**；「恢复原文」可随时切回
- 翻译结果有缓存，同一批名字第二次点几乎 0 秒
- 关键词搜「结果语言=中文」时，点每条结果下面的「翻译成中文」会翻整条记录

## 6. 生产端怎么用（三页）

1. **选项 1 · 主模型配置**：填 Key / 选模型（不填也能跑，只是没有"主管"给建议）
2. **选项 2 · 画布编排**：左边选插件 → 「＋ 添加这个节点」→ 画布上连线（一进多出=并行）
   - 「🔍 适应窗口」「↶ 撤销」「× 清空」都在工具栏
   - 「导入 / 导出工作流」可以存成 JSON 复用
3. **选项 3 · 开始工作**：放数据（单条 / 批量）→ 「▶️ 开始工作」→ 看状态灯和每步耗时

插件怎么写：见 [插件接口.md](插件接口.md)。

## 7. 换自己的数据

```bash
python tools/从zip导入.py --zip MIMIC-IV.zip --prefix miv   # 有授权的数据集
python tools/建病例库.py 100000        # 聚合成 case_corpus
python tools/补年龄段.py && python tools/补性别.py
python tools/建搜索索引.py
python tools/建向量.py
```

详见 [数据说明.md](数据说明.md)。**MIMIC / eICU 的数据不要提交到公开仓库。**
