# 插件接口（怎么写一个自己的插件）

框架 A 是「微内核 + 插件」：内核只负责调度、超时、重试、日志，**所有具体能力都在插件里**。
写插件不用改内核，一个文件就是一个能力。

---

## 最小插件（20 秒看懂）

`plugins/my_cleaner_我的清洗.py`：

```python
# -*- coding: utf-8 -*-
from base_基类 import BasePlugin


class MyCleaner(BasePlugin):
    name = "我的清洗"

    def execute(self, text_data: str) -> str:
        return " ".join(str(text_data or "").split())


PLUGIN_CLASS = MyCleaner        # 可选：显式声明用哪个类（不写就自动找 BasePlugin 子类）
```

放进 `plugins/`，重启框架 A，第 2 页「新节点用什么」里就会出现「我的清洗」。

## 接口约定

### 必须实现

```python
def execute(self, text_data: str) -> str: ...
```

- 入参：**上一步的输出**（第一步时是用户在「开始工作」页贴的原文）
- 返回：**新的字符串**。返回 `None` 或其它类型会被内核判为失败
- 不要把入参改掉再返回，返回新字符串（出问题时才好排查"哪一步改坏了"）
- **不要吞异常**：抛出来，内核会标红、记日志、按设置重试

### 可选：声明依赖的字段

```python
class MyPlugin(BasePlugin):
    REQUIRES = ["text"]                 # 需要上游提供什么
    OUTPUT_FIELDS = ["text", "tokens"]  # 自己产出什么
```

内核在开跑前会用 `REQUIRES` / `OUTPUT_FIELDS` 校验连线：
上游没产出的字段被下游需要时，**当场报错**，而不是跑到一半才炸。

### 可选：结构化输出

文本串不够用时（比如要拆成 title / summary / keywords），覆盖 `execute_rich`：

```python
def execute_rich(self, ctx: dict) -> dict:
    text = ctx.get("text", "")
    return {"title": ..., "summary": ..., "keywords": [...]}
```

默认实现是 `{"text": self.execute(ctx["text"])}`，所以不写也能用。

### 可选：元信息

| 属性 / 方法 | 作用 |
|---|---|
| `name` | 界面上显示的中文名 |
| `needs`（插件目录 json）或 catalog 里的 `needs` | 声明是否需要联网 / 是否需要模型 |
| `execute_rich(ctx)` | 结构化执行入口 |
| `before/after` 钩子 | 目前没有，需要就加在基类（改一处，全部插件生效） |

## 内核替你做的事

- **超时**：单步默认 180 秒（`config_配置.STEP_TIMEOUT`，界面也能改）
- **重试**：失败且错误「可重试」时按 `retry_max` 再试（`core/retry_重试.py`）
- **失败即停**：某步失败后，下游步骤标 `skipped`，不会带着坏数据继续跑
- **子进程隔离**：不需要模型的插件可以放到子进程跑，超时能硬杀（`worker_插件.py`）
- **日志**：`data/app.log`（JSON 行），界面有状态灯和耗时
- **报错翻译**：`core/errors_报错翻译.py` 把常见异常翻成人话

---

## 拿数据 / 调模型

- 要模型：把 `needs.model` 声明为真，内核会先确认 Ollama 在线；
  模型名写在 catalog 的 `model` 字段，运行时通过 `ctx["model"]` 传进来
- 要联网：`needs.network` 声明为真，抓取类插件请先过 `core/url_safety.py`
- 要写库：参考 `plugins/db_writer_入库.py`，它把 `execute_rich` 的 dict 落到 SQLite，
  表名/字段由节点配置决定

## 自我测试（推荐）

插件单独可测，不需要开界面：

```python
# test_my_cleaner.py
import sys; sys.path.insert(0, "plugins")
from my_cleaner_我的清洗 import MyCleaner

p = MyCleaner()
assert p.execute("  a   b  ") == "a b"
print("OK")
```

仓库里 `test_mod2_画布.py`、`test_mod7_入库.py` 就是这种写法，可以直接抄。

## 常见坑

| 现象 | 原因 |
|---|---|
| 画布里看不到新插件 | 文件名不是 `*.py`、类没继承 `BasePlugin`、或没重启框架 A |
| 报「缺少上游字段」 | 插件声明了 `REQUIRES`，但上游 `OUTPUT_FIELDS` 里没有 |
| 步骤一直 `pending` | 前面某步失败，被标记 `skipped` 了 |
| 返回 dict 报类型错误 | `execute()` 必须返回 `str`；要结构化请用 `execute_rich()` |
| 子进程里 import 失败 | 插件里只用标准库 + 项目内模块；第三方包要在主环境装好 |
